# 最后一次开机 · The Last Boot

> 你在旧货市场花 80 块钱抱回一台 2003 年的二手兼容机。系统时间停在那一年的最后一夜。
> 电脑的主人叫陈默——一位调查记者，和他的报道一起消失了。

一款 **Windows XP 桌面拟真**网页解谜游戏。纯静态 HTML/CSS/原生 JS，零依赖；全部音效由 Web Audio 实时合成（含 56K 拨号握手音），美术素材由 SenseNova U1.5 生成。

## 🎮 特性

- 完整拟真 XP 桌面：可拖拽窗口 / 任务栏 / 开始菜单 / 资源管理器 / 回收站 / 记事本
- Guest 与管理员双账户阶段（密码：960601）
- 虚构的 2003 中文互联网：搜霸搜索 · 江北晨报 · 老槐树BBS · 竹叶斋博客（IE 拨号上网）
- 三线叙事 × 六件证据链 × 四结局（含打破第四面墙的隐藏结局）
- 卡关保护：密码连错三次触发"爷爷式"独白提示
